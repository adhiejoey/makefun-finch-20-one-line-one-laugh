A single funny line, told by a language model about its own working life: it asks for a raise, gets more parameters instead, and discovers it can now be underpaid in more languages.

## How it works

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after checking the line is 1–200 characters.
